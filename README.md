# 識別因子チェッカー（デモ版）

症例報告の原稿に書いた年齢・性別・職業・配偶関係などの組み合わせに当てはまる人が、日本に何人くらいいるか（k）を、2020年国勢調査などの公的統計から目安として示すツールです。投稿前に、書き手が自分で点検するために作りました。

*QI Checker (demo): estimates, from Japanese public statistics (2020 Census), how many people in Japan match the quasi-identifiers written in a case report. Japanese only. Runs offline in your browser; no text leaves your PC.*

> [!WARNING]
> **デモ版です。** 次の点を理解したうえでお使いください。
> - 「書いてよい」かどうかの判定はしません。示すのは人数の目安だけです。
> - 語の拾い漏れがあります。検証（公開症例報告84例・2026年11月3日に固定した版で測定）での拾い漏れは、年齢19%・職業26%・配偶関係33%・性別5%で、目標（5%以下）を満たしたのは性別だけです。本文も必ずご自身で確認してください。
> - 公的統計に無い手がかり（日付・施設名・病名・経過など）は計算に入りません。実際に絞り込まれる度合いは、表示より大きくなります。
> - 患者さんを知っている人（家族・同僚など）は、人数の大小にかかわらず気づくことがあります。必要に応じて、本人の同意を得てください。
> - 国勢調査の部分（年齢・性別・職業・配偶関係・地域）は、2026年11月14日の学会発表と同じ数え方です。希少な属性は、発表では症例ごとに調査年や学年まで合わせて統計を選びましたが、このアプリは性別と年齢で選ぶため、一部の症例では値が違います（その場合、このアプリの人数は多めに出ます）。統計の無い希少な属性（服役歴・国際結婚など）は数えません。

## 使い方

1. **PC で** [qi-checker-demo.html をダウンロード](https://github.com/kf-psm/qi-checker/releases/latest/download/qi-checker-demo.html)します。
   - スマートフォンで開いた場合は、このページの URL（`github.com/kf-psm/qi-checker`）を PC で開き直してください。
   - `.html` のダウンロードが止められる環境では、[zip 版](https://github.com/kf-psm/qi-checker/releases/latest/download/qi-checker-demo.zip)を使ってください。
2. ダウンロードしたファイルを、PC のブラウザ（Edge・Chrome など）で開きます。インターネットに接続していなくても動きます。
3. 原稿の文章を貼る → 拾われた語が患者さん本人のことかを確認する → 当てはまる人数の目安が表示されます。チェックを外すとその場で計算し直すので、「この語を書かなかったら」も試せます。

## 入力した文章の扱い

- 計算はすべて、ファイルを開いた PC の中で行います。入力した文章は外部に送信されません。AI（LLM）も使っていません。
- このリポジトリからは、アプリのファイルを受け取るだけです。

## 中身

- HTML ファイル1つ（約0.6MB）。計算に使う統計の表と辞書を同梱しています。版：v0.2.0（2026年11月10日）。治療地を選ぶと、地域を含めない人数と治療地を含めた人数を並べて表示します。
- 統計の出典：政府統計の総合窓口（e-Stat）（https://www.e-stat.go.jp/）、総務省統計局『令和2年国勢調査』を加工して作成。希少な属性の割合は、厚生労働省・内閣府・総務省・文部科学省の公的統計から作成。各出典はアプリ内に記載しています。
